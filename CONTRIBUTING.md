# Contributing

Thank you for wanting to improve this beginner-friendly repo!

### Guidelines:
1.  Keep language **super simple** - Assume reader is on Day 1
2.  Every code file must have:
    - Header comment explaining WHAT & WHY
    - Example code that runs
    - 2-3 exercises for the reader
3.  No advanced jargon without explanation
4.  Add your example to the relevant chapter folder

### How to add a new lesson:
1. Place it in correct folder (e.g., `02-control-flow/`)
2. Name it `number_topic.py` e.g., `03_for_loop.py`
3. Use this template:
```python
"""
TOPIC: Title
WHAT: 1-line explanation
WHY: Why is this important?
"""

# --- CONCEPT ---

# --- EXAMPLES ---

# --- EXERCISES ---
# 1. ...
```
