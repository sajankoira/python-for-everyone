# Python For Everyone - Learn From Scratch 🐍

> A complete, beginner-friendly Python course built in public. Learn Python from absolute zero - no prior programming knowledge needed!

This repo is both **my learning journal** and **your free textbook**. Every lesson, example, exercise, and project I create will be committed here.

### 🌟 Why this repo?

- **Zero to Hero**: Starts from "What is Python?" to building real projects
- **Learn by Doing**: Every concept has runnable code + exercises
- **Open for All**: Anyone can fork, learn, and contribute
- **Well Documented**: Simple English, lots of comments, real-world examples

## 🚀 How to Use This Repo

1.  **Clone it:**
    ```bash
    git clone https://github.com/YOUR_USERNAME/python-for-everyone.git
    cd python-for-everyone
    ```
2.  **Prerequisites:** Python 3.8+ installed. Check with:
    ```bash
    python --version
    # or
    python3 --version
    ```
3.  **Start Learning:** Go to folder `01-basics/` and run:
    ```bash
    python 01_hello_world.py
    ```
4.  Each file is a self-contained lesson with:
    - Concept Explanation (in comments)
    - Example Code
    - Your Turn! (Exercises)
    - Interview Tip (where relevant)
