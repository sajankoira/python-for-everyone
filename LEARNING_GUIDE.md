# How I Learned Python - Step by Step Guide for You

If you are absolute beginner, follow exactly this order. Don't skip!

## Phase 1: Day 1-2 - Setup & Mindset

### Step 0: Install
- Install Python from python.org (Check "Add to PATH")
- Install VS Code
- Install Git

Verify:
```bash
python --version
git --version
```

### Step 1: Hello World (01-basics/01_hello_world.py)
- Understand print()
- Run: `python 01-basics/01_hello_world.py`
- Modify and re-run!

**Key Takeaway:** You can make computer display anything!

## Phase 2: Variables
File: `02_variables_and_datatypes.py`
- Practice f-strings A LOT
- Create your bio variables
- Understand dynamic typing

## Phase 3: Input/Output
- Make interactive programs
- Remember: input() -> string
- Convert with int(), float()

---

## My Learning Rule: 50-50

- 50% time reading/understanding code in repo
- 50% time MODIFYING and BREAKING it!

Don't just read. Change values, create errors, fix them. That's how you learn.

## How to Commit Your Progress?

This repo is also teaching you Git!

After completing each file:
```bash
git add .
git commit -m "Completed: Variables and Datatypes - learned f-strings"
git push
```

Your GitHub green graph will show your consistency!
