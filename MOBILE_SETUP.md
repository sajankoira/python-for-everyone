# Learn Python on Android 📱 - Full Guide

You don't need a laptop! You can do everything from your phone.

## Step 1: Run Python on Android

**Best app: Pydroid 3 (Free)**
1. Play Store -> Search "Pydroid 3 - IDE for Python 3"
2. Install -> Open
3. It has Python ready! Try: print("Hello World")

**Alternative (No install):**
- Go to https://www.programiz.com/python-programming/online-compiler/
- Works in Chrome mobile, just paste code and Run

**For this course:**
- Copy code from 01-basics/01_hello_world.py 
- Paste into Pydroid 3 and press Run button

## Step 2: Create GitHub Repo from Android Chrome (2 mins)

**No zip needed!**

1. Chrome on phone -> Go to https://github.com/new
2. Repository name: `python-for-everyone`
3. Description: `Learn Python from Scratch`
4. Select **Public**, **DON'T check Add README**
5. Tap **Create repository**

Now repo exists but empty at https://github.com/sajankoira/python-for-everyone

## Step 3: Get code into repo - Two options for Android

### Option A: Let me push for you (30 sec, easiest)
1. Chrome -> https://github.com/settings/tokens/new
2. Note: `temp-upload`
3. Expiration: 7 days
4. Check ✅ `repo` (full control)
5. Tap Generate token -> **COPY** the token starting with `ghp_`
6. Paste token here to me, I'll push all 21 files to your repo in 10 seconds
7. After I push, go back and **Delete token** (important for security)

### Option B: Manual upload without token
On the empty repo page you just created:
1. Tap "uploading an existing file" link
2. Android file picker opens BUT you don't have files...
   
**Workaround:**
- Use GitHub's "Add file" -> "Create new file" button
- Name: `01-basics/01_hello_world.py`
- Copy-paste content from here (I will give you each file)
- Commit...

This is slow - that's why Option A is 100x faster on mobile.
